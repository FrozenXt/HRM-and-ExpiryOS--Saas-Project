# HRM-and-ExpiryOS--Saas-Project
This is a SaaS project. It is not just a traditional HRM , it has a expiry OS as well what it does is, when you upload any document it will give you reminder if it is going to be expired. it is made not just for Nepal , it can work with India as well as per their rules. It is built with Express.js , Mongo and react will be the frontend framework.
